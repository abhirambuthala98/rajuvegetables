RAJU VEGETABLES - FINAL MANUAL PROTOTYPE

RUN:
1. Extract the ZIP.
2. Open index.html in Chrome, or open the folder in VS Code and use Live Server.
3. Demo Owner: owner / 1234
4. Demo Customer: customer / 1234

FEATURES:
- Owner/customer role selection and login
- Owner dashboard
- Purchases (box, bag, kg, piece)
- Inventory
- Customer management
- Multi-item customer bills
- Automatic bill totals
- Amount paid and balance due
- Customer ledger
- Record later payments
- Bill sharing with phone Web Share / clipboard fallback
- Printable bill
- Customer statement sharing
- Daily prices
- Expenses
- Sales
- Estimated COGS and net profit
- Minimum daily profit target
- Daily reports
- Customer portal with restricted own data
- Browser localStorage persistence

IMPORTANT:
This is a local/offline prototype. Data is stored in the browser's localStorage on the device/browser where it is used. It is not yet a cloud database and should not be treated as a secure production system.
